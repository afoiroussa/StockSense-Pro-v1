# 📦 StockSense Pro v10

Εφαρμογή διαχείρισης αποθεμάτων για ΑΦΟΙ ΡΟΥΣΣΑ ΟΕ

**Δημιουργός:** Christos Roussas

## Πώς να ανεβάσεις στο GitHub Pages

### Βήμα 1 — Φτιάξε λογαριασμό
1. Πήγαινε στο **github.com**
2. Πάτα **Sign up** (Εγγραφή)
3. Γράψε email, κωδικό, username (π.χ. `afoi-roussa`)
4. Επιβεβαίωσε το email σου

### Βήμα 2 — Φτιάξε νέο Repository
1. Πάτα το **+** πάνω δεξιά → **New repository**
2. Όνομα: `stocksense`
3. Επιλέξε **Public** (απαραίτητο για free GitHub Pages)
4. Πάτα **Create repository**

### Βήμα 3 — Ανέβασε τα αρχεία
1. Πάτα **uploading an existing file**
2. Σύρε τα αρχεία: `index.html` και `README.md`
3. Πάτα **Commit changes**

### Βήμα 4 — Ενεργοποίησε το GitHub Pages
1. Πήγαινε **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main**, Folder: **/ (root)**
4. Πάτα **Save**

### Βήμα 5 — Η εφαρμογή είναι online!
Μετά από 2-3 λεπτά η εφαρμογή θα παίζει στο:
**https://[username].github.io/stocksense**

## Κωδικός Πρόσβασης
Η εφαρμογή έχει προστασία με κωδικό.
Μόνο όσοι ξέρουν τον κωδικό μπορούν να τη χρησιμοποιήσουν.
